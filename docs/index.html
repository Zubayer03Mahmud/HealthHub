HealthHub - Comprehensive Healthcare Management System

HealthHub is a web-based healthcare management system designed to streamline access to essential healthcare services, hospital facilities, medical consultations, and health record management. Built with Node.js, Express.js, and JavaScript, the platform strictly follows the Model-View-Controller (MVC) architectural pattern[cite: 1, 3] and complies with the JSDoc Documentation Standards and the HealthHub JavaScript Coding Standards.

🌟 Project Overview

HealthHub is an independent, centralized platform that provides access to healthcare-related information and emergency services without requiring users to visit multiple websites or contact hospitals individually. It reduces the time needed to locate emergency medical resources while maintaining data accuracy and system reliability.

🏛️ System Architecture (MVC)

HealthHub is architected using the Model-View-Controller (MVC) pattern:

  • Model (src/models/): Manages data structures, state validation, and data operations[cite: 1, 2].
  • View (public/): A client-side Single Page Application (SPA) interface rendered with pure JavaScript modules, semantic HTML5, and CSS3.
  • Controller (src/controllers/): Handles incoming HTTP API requests, communicates with models, and returns structured JSON responses[cite: 1, 2].

🏥 Core Features (13 SRS Modules)

  1. User Registration: Validates required fields, checks for duplicate email addresses, verifies matching passwords, encrypts passwords before storage, and creates role-based accounts.
  2. User Login & Authentication: Authenticates credentials securely, manages sessions, and grants role-based access control.
  3. Hospital Directory Search: Enables search by hospital name, city, or district to display departments, operating hours, bed capacity, and contact information.
  4. Appointment Booking & Management: Provides slot selection, appointment booking, cancellation workflows, and schedule views for patients and doctors.
  5. Doctor Profile Management: Allows patients to view doctor qualifications, experience, fees, and ratings, while enabling doctors to update consultation hours and profiles.
  6. Search Blood in Blood Bank: Locates blood availability across regional blood banks and hospitals filtered by blood group (A+, A-, B+, B-, AB+, AB-, O+, O-) and area.
  7. Search Vaccine & Anti-Venoms: Searches availability of emergency polyvalent antivenom and preventive vaccines across hospitals and pharmacies.
  8. Manage Emergency Contacts: Displays 24/7 hospital emergency room hotlines and ambulance numbers with direct "Call Now" phone dialing.
  9. Search ICU & CCU Availability: Real-time occupancy tracking for Intensive Care Units (ICU) and Coronary Care Units (CCU) to assist critical emergency transfers.
  10. Hospital Recommendation Engine: Generates hospital suggestions tailored to location, medical condition, required specialty, cost tier, and ICU needs.
  11. Ambulance Service Search: Searches available ambulance service providers and mobile ICU units by city or district.
  12. Online Payment Integration: Facilitates secure online payments for appointments with payment summaries, multiple methods, and digital invoice receipts.
  13. Personal Health Record Upload: Enables secure upload, categorization, viewing, and deletion of medical records in PDF, JPG, JPEG, and PNG formats.

👥 User Roles & Permissions

  • General Users (Patients): Create accounts, search hospitals, book appointments, upload health records, make online payments, and access emergency services.
  • Doctors: Manage professional profiles, availability schedules, consultation fees, and view patient appointment requests.
  • Hospital Administrators: Update hospital details, total bed counts, departments, and live ICU/CCU availability.
  • Ambulance Providers: Manage vehicle details, service areas, operational statuses, and emergency contact numbers.
  • System Administrators: Manage user accounts, maintain system security, monitor database integrity, and oversee performance.

💻 Technology Stack & Environment

  • Runtime Environment: Node.js (v18.0.0+)[cite: 1, 3]
  • Backend Framework: Express.js
  • Database Server: MySQL Database Server
  • Frontend: Vanilla JavaScript (ES6+), HTML5, CSS3
  • Documentation Tool: JSDoc
  • Testing Framework: Node.js Native Test Runner (node:test, node:assert/strict)
  • Key Dependencies: bcryptjs, express-session, cookie-parser, dotenv, multer
